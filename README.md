# Velora

A production-ready e-commerce storefront for a contemporary lifestyle boutique.

## Stack

React, TypeScript, Vite, Tailwind CSS, TanStack Router (file-based), shadcn/ui, Zustand.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

Copy `.env.example` to `.env` and set `VITE_API_URL` when the NestJS API is available.
